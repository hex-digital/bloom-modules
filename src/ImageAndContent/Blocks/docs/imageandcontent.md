# ImageandContent

---

The Image and Content block is an outer block which uses the Base Image module. It has an image on one side, with content on the other. This block accepts innerblocks which are displayed on the content side.

This block has controls for horizontal and vertical alignment, wrapper size, image display (crop or contain) and image placement (left or right).
